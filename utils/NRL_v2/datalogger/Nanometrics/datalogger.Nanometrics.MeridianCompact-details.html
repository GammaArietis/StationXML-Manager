### Full-Scale Voltage When configuring the Meridian Compact digital recorder, the user sets the input (full-scale) voltage range, which translates to choosing an preamplifier gain. Gains of 1, 2, 4 and 10 correspond to input range values of 40, 20, 10 and 4 Vpp respectively. ### Final Filter Phase The operator can configure the digitizer to use linear-phase or minimum-phase decimation filters. ### DC Filter The Library includes a response for a final IIR DC removal filter with a low-frequency corner of 1 mHz (0.001 Hz) as an example. The filter corner can be set to any value of integer mHz between 1 and 1000 mHz. For other corner frequency values, set the pole for this filter instead to the selected corner frequency times 2 * pi.
