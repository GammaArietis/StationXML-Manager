Below is some configuration-specific information to help you locate your instrument response. ### Sensitivity Nominal sensitivity in V/m/s\*\*2 is > G in V/m/(s*s) = [Full scale voltage / Clip level] / [9.80665 m/(s\*\*2)] The responses here apply to uniaxial, triaxial, and borehole versions. ### Analog Filter Type The RT131A-02 was initially manufactured using the SF3000L 2-pole analog filter. Subsequently, the SF1500S filter was substituted. There should be a plate or decal on the side of the accelerometer that tells you which type of filter was used. If not, it probably uses the SF3000L filter.
